Selectors
How do selectors work?

Selectors are used to select the HTML elements based on their id, class, type, attributes, values of attributes, etc. CSS selectors are to "find" (or select) the HTML elements you want to style. There is no selector here, but the above text is for understanding the concept of selectors. if we need to style this text, we can use element selector to select the text and apply styles to it.

Element selectors
What is an element selector?

An element selector is used to select HTML elements based on their tag name. For example, p { } selects all paragraph elements. Here I am using no selector to style this text, but if we need to style this text, we can use element selector to select the text and apply styles to it.

Class selectors
What is a class selector?

A class selector is used to select HTML elements based on their class attribute. For example, .myClass { } selects all elements with the class "myClass". Here i am using a class selector to style this text.

ID selectors
What is an ID selector?

An ID selector is used to select HTML elements based on their id attribute. For example, #myId { } selects the element with the id "myId". I can target this text using the ID selector to style it.

Inline selectors
What is an inline selector?

An inline selector is used to select HTML elements based on their style attribute. For example, [style] { } selects all elements with a style attribute. This is already styled using an inline selector.

Combined selectors
How do we combine selectors?

A combined selector is used to select HTML elements based on a combination of the above selectors. For example, .myClass { } selects all elements with the class "myClass", and #myId { } selects the element with the id "myId". I am using a combined selector to style this text. I can use the class selector and ID selector together to style this text.
